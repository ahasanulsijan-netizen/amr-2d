# amr 2d

amr 2d is a prompt-driven 2D animation studio. It runs in your browser and creates looping vector scenes without an account, AI model, API key, or service quota. Its procedural generator recognizes common subjects, actions, colors, and settings, then combines them into a scene. It now matches subjects in the order they appear and includes more animals, characters, and environments. Prompts outside its vocabulary get an abstract character. It does not generate arbitrary or photorealistic imagery, or retell every event in a long prompt.

## Run it

Open [amr 2d](https://ahasanulsijan-netizen.github.io/amr-2d/) or double-click `Run amr 2d.bat` / open `index.html` in a current browser. No installation or setup is needed.

## Create and export

The description box has no character cap and grows as you type. Enter a prompt such as “a frog hops across lily pads under the moon” or “a hedgehog gathers apples in an autumn orchard,” choose a social format, and click **Generate video** once. YouTube 16:9 is selected by default at 1920×1080; TikTok, YouTube Shorts, Instagram, and Facebook presets set their matching frame shapes at 1080-class resolution. The scene is centered and cropped to the selected ratio. Choose a video length next to the playback timeline; the timeline updates to match. The scene is created and recorded locally; after it finishes, click **Download** to save the WebM. Keep the browser tab open while it renders. Use the timeline and play button to preview the looping animation. The **+** button in the prompt box adds local reference-frame thumbnails; they are not uploaded or used to generate the scene.

**Export SVG** downloads an animated vector file that can be opened in a browser or edited in vector software. Choose **1 minute**, **3 minutes**, or **5 minutes** from the video length selector.

There is no service quota, but rendering and recording speed are limited by your computer and browser.
